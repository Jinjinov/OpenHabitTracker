## Do you want to submit a pull request?
Please create a new issue before submitting a pull request, and discuss the changes there first.
Pull requests with a lot of changed files and/or a lot of changed lines are not allowed, unless they were explicitly approved after a discussion in the issue.

## Do you want to create a new issue?
Please create a separate issue for each bug or feature.

## Do you want to use AI?
Only a human can create issues and pull requests, with their own GitHub account.
Automated posts made by bots with their own GitHub accounts are not allowed - I will not have a conversation with your bot.
AI can help, but what you post must at least look like a human wrote it, not a wall of text.
Read everything your AI wrote before you post it.
